G5 — интерактивное вводное обучение для уже работающего Crane Simulator.

Работай внутри существующего проекта; G1–G4 уже приняты. Не создавай проект заново и не переделывай механику.

1. Проверь git status; не затрагивай чужие изменения, не пушь в репозиторий без запроса.
2. Прочитай AGENTS.md, docs/G5_ONBOARDING.md, .agent/G5_IMPLEMENTATION.md и существующие SPEC/ARCHITECTURE/QA/TASKS/STATE/DECISIONS.
3. Один раз выполни `node tools/apply-g5.mjs` из корня проекта. Проверь его отчёт и git diff: скрипт регистрирует G5 в действующих MD без удаления старых решений. При ошибке разбери её, не продолжай молча.
4. Изучи актуальный src/App.vue, UI-стили и браузерные тесты. Реализуй G5 по спецификации: затемнение, две кнопки, трёхшаговый spotlight для сцены, камеры, крана, повторное обучение из «Справки».
5. Сделай тесты, запусти `npm run check` и `npm run test:e2e`, проверь живой браузер, сними evidence/G5/*.png. Убедись, что G1–G4 работают по-прежнему.
6. Обнови TASKS.md и STATE.md по фактической работе. Остановись на G5 AWAITING_APPROVAL, покажи короткий отчёт и попроси явную приёмку. Не начинай G6.

Не задавай мелкие вопросы о реализации, принимай обратимые технические решения сам. Если невозможно сделать именно требуемое поведение — укажи препятствие и остановись, а не подменяй результат.
