# G5 · Интерактивное обучение

1. Запустите `npm run dev` из корня проекта и откройте `http://localhost:5173/`. Появится стартовая карточка с двумя действиями. Нажмите «Пройти обучение».
2. Проверьте три шага. Сначала выделяется нижняя панель камеры, затем 3D-сцена, затем правая панель крана. На первых двух шагах «Далее» и «Пропустить» одинаковой ширины. На стартовой карточке и при навигации клавишей Tab нет рамок фокуса. На шаге сцены колесо мыши и перетаскивание поверх сцены не меняют ракурс.
3. Нажмите «Завершить», обновите страницу и проверьте, что карточка появилась снова. Нажмите «Пропустить обучение», затем запустите тур из «Справки» и закройте через Escape.

- `npm run check` — проверка типов, 26 модульных тестов и сборка прошли.
- `npm run test:e2e` — прошли 4 теста G5 и 13 регрессионных тестов G1–G4. Проверены повторный показ при обновлении и переоткрытии вкладки, клавиатурная навигация, блокировка ввода, повтор с грузом на захвате и обновление координат при изменении размера окна.
- Отдельная проверка Chrome на ширине 390 px подтвердила настройки обычной анимации, подсветку нижней панели крана и восстановление прокрутки после Escape.
- Firefox и аппаратный WebGL не проверялись.
