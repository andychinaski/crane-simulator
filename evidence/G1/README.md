# G1 · Визуальная основа

Снимки работающего приложения из Chrome с программным WebGL 2.

- [1672×941](main-1672x941.png)
- [1440×900](main-1440x900.png)
- [1280×720](main-1280x720.png)

## Проверки

- `npm run check` — проверка типов, три модульных теста и статическая сборка прошли. Vite сообщил о файле JavaScript размером 593 КБ (164 КБ после gzip).
- `npm run test:e2e` — пять тестов прошли. На трёх целевых размерах проверены WebGL 2, расположение панелей, диапазоны, исходные значения, справка и отсутствие ошибок консоли. Отдельно проверены экран ошибки при недоступном WebGL и компоновка при ширине 390 px.
- Собранное приложение открыто отдельно в Chrome при 1440×900. Сцена отрисовалась через WebGL без ошибок консоли. Firefox и аппаратный рендеринг на G1 не проверялись.

## Отличия от референса

- Использована ортографическая камера. Ящик в кадре расположен немного ниже, зазор между ручкой и захватом заметно больше.
- Процедурные материалы и освещение дают другое направление тени, более ровный металл, упрощённые бетон и древесину.
- Положение ручек ползунков рассчитывается по реальным диапазонам из `config/controls.json`. Под регуляторами указано, что управление и демонстрация в работе.
