## Ручная проверка

Запусти `npm run dev` и открой `http://localhost:5173/`.

1. Пройди или пропусти G5 и выбери «Попробовать вручную» с включёнными подсказками.
2. На шаге 4 выставь 54°, затем 49° и снова 54°. При отклонении галочка исчезает, а «Далее» блокируется. При возврате к 54° шаг снова считается выполненным. На шаге 8 нажми End на ползунке троса, чтобы опустить ящик до фактического упора.
3. Открой «Выбрать режим». Попробуй ручной режим без подсказок и запусти демонстрацию. Нажми «Стоп» во время переноса и продолжи вручную с захваченным ящиком.
4. Измени масштаб камеры, проверь «Сбросить вид» и круговую стрелку по отдельности. При сбросе изменённого сценария сначала нажми «Отмена», затем повтори и подтверди.
