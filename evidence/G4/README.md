# G4 · Демонстрация и выпуск

1. Откройте `http://127.0.0.1:4173/` или запустите `npm run dev` из корня. По желанию измените позу крана и нажмите «Демонстрация». Панель сообщает о восстановлении начального положения. Бегунки двигаются вместе с механизмами. После каждого шага результат остаётся виден 0,5 с до следующего действия. В конце появляются «Демонстрация завершена» и «На площадке», захват поднимается пустым.
2. Поставьте скорость на 35%, снова запустите демонстрацию и нажмите «Стоп» во время переноса. Движение должно прекратиться в текущей позе. Ящик остаётся захваченным. Теперь можно изменить длину троса вручную.
3. Во время демонстрации попробуйте повернуть камеру или изменить масштаб. В «Справке» описаны ручной цикл, защита от столкновения пустого захвата с ящиком и правила демонстрации.
4. Для независимой проверки ручного режима откройте [маршрут G3](../G3/README.md) и повторите его из начальной позы.

## Проверки

- `npm run check` — типы, 26 модульных тестов и статическая сборка прошли. Самый большой файл JS — 324 КБ, 78 КБ после gzip.
- 13 тестов Playwright прошли на финальной сборке в Chrome с программным WebGL. Проверены ручная и автоматическая доставка, подсказки, отсутствие ошибок консоли, остановка, интерфейс на трёх настольных размерах и на ширине 390 px.
- Браузерный тест подтвердил промежуточные значения троса и паузу перед захватом. После остановки в середине поворота изображение сцены осталось неизменным, ящик сохранил сцепление. Ручное изменение длины троса сдвинуло ящик вместе с захватом.
- Firefox и аппаратный WebGL не проверялись.
