# STATE — точка восстановления

- **Проект:** Симулятор крана.
- **Статус:** проект завершён, G1–G4 приняты владельцем.
- **Явные подтверждения владельца:** G1 — «Принято», G2 — «Похуй принято, делай дальше», G3 — «Принято», G4 — «Слушай, классно. Считаю что принято».
- **Исходники:** демонстрация переносит ящик теми же приводами, что используются вручную. Бегунки отображают фактические положения, между действиями паузы 0,5 с с подписью результата. «Стоп» сохраняет позу и груз, отменяет следующий шаг даже во время паузы. Камера доступна весь цикл.
- **Проверки G4:** `npm run check` — типы, 26 модульных тестов и сборка прошли. 13 тестов Playwright прошли в Chrome с программным WebGL. Подтверждены промежуточные значения бегунка и пауза перед захватом, доставка и остановка в середине поворота.
- **Доказательства:** `evidence/G4/` — три снимка и шаги проверки. Сборка доступна по `http://127.0.0.1:4173/?g4=step-by-step`. Для запуска из исходников — `npm run dev`, адрес `http://localhost:5173/`.
- **Известные ограничения:** Firefox и аппаратный WebGL не проверялись. Рабочая папка без Git-репозитория. Перед повторным `npm ci` на Windows остановить Vite.
