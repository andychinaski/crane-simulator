# Crane Simulator · G6 — режимы и пошаговое ручное управление

Это **аддитивный пакет**, а не новый проект. Не заменяет `src/`, `App.vue`, `AGENTS.md` или документы G1–G5 целиком.

## Применение

1. Убедиться, что локальный G5 работает и текущая версия сохранена в Git. Рекомендуемая ветка: `feature/g6-modes` от принятой G5 (не от старой G4).
2. Распаковать содержимое архива **в корень действующего проекта**, где лежит `package.json`. Появятся `docs/G6_MODES_AND_GUIDE.md`, `.agent/G6_IMPLEMENTATION.md`, `config/g6-route.json`, `tools/apply-g6.mjs`, `START_G6.txt`.
3. Передать агенту текст `START_G6.txt`. Агент сначала сверит рабочий код G5, затем выполнит `node tools/apply-g6.mjs` и проверит diff.
4. После реализации агент самостоятельно проверяет G6 и останавливается на `G6 AWAITING_APPROVAL`. Пока владелец не принял G6, не начинать G7.

## Что добавит скрипт

Только секции **G6** в `AGENTS.md`, `docs/SPEC.md`, `docs/ARCHITECTURE.md`, `docs/QA.md`, `.agent/TASKS.md`, `.agent/STATE.md`, `.agent/DECISIONS.md`. Существующие файлы не заменяются, старые блоки и G5 не удаляются. Повторный запуск идемпотентен. Исходный код, Git и npm скрипт **не трогает**.

## Важная оговорка о репозитории

G5 принят и влит в `master` через PR #1 (коммиты `c7adf15`, `f5c95b4`, merge `772129d`). Рабочий код всё равно нужно прочитать перед изменениями; не заменять реализацию G5 старыми файлами.

## Главная задумка

После стартового обучения (или его пропуска) появляется выбор: «Демонстрация» или «Попробовать вручную»; для ручного режима — чекбокс «С подсказками». Кнопки демо/стоп удаляются из правой панели. На сцене вверху справа — компактные действия остановки/повторного запуска сценария. Подсказки и интерактивная зелёная карточка находятся под рычагами справа. Ручная подсказка не управляет краном за пользователя.
