# Crane Simulator — G7: минорные улучшения интерфейса

Аддитивный пакет **для уже реализованного G6**, не новая копия приложения.

## Состав

- `docs/G7_UI_POLISH.md` — полные требования и визуальные критерии.
- `.agent/G7_IMPLEMENTATION.md` — порядок работы, риски, проверки, точка остановки.
- `assets/reference/g7/` — пользовательские скриншоты и референс игрового уведомления.
- `tools/apply-g7.mjs` — безопасно добавляет ссылки/разделы G7 в существующий Harness. Исходники и конфигурацию приложения не трогает. Идемпотентен.
- `START_G7.txt` — готовое сообщение coding-агенту.

## Как использовать

1. В текущем проекте **сначала сохрани рабочую G6 в Git** и создай ветку `feature/g7-ui-polish` от ветки, содержащей **фактический завершённый G6** (не от устаревшего master). Сверь `git status`.
2. Распакуй содержимое архива **в корень действующего проекта** рядом с `AGENTS.md` и `package.json`. Не распаковывай поверх каталогов `src/`; пакет не содержит исходного кода.
3. В новой агентской сессии открой **эту же папку проекта** и передай `START_G7.txt`.
4. Агент сам сверит текущую G6, выполнит `node tools/apply-g7.mjs`, реализует изменения, проверит и остановится на `G7 AWAITING_APPROVAL`.

**Ничего не удалять, не сбрасывать Git и не запускать `git checkout -f`/`git clean -fd`.** Для G7 не нужна установка библиотек: Vue + CSS + существующие подсистемы камеры/режима.

## Важно: незакрытое решение

Владелец упоминал будущее **перемещение карточки ручных подсказок**, но новое точное место пока не назвал. **G7 изменяет её внешний вид и состояния, не переносит в произвольное место.** До дальнейшего решения сохраняй текущее G6-размещение под правыми регуляторами/статусами.

## Почему нельзя слепо доверять состоянию ветки master

При подготовке пакета доступная публичная веб-версия `master` показывала файлы прежней итерации. Реализованный G6 может быть только в локальной ветке или ещё не влит в master. Перед работой агент обязан считать источником истины **локальный работающий G6**, проверить историю, не пересоздавать G5/G6 и не откатывать новые функции.
