# Симулятор крана

Локальное веб-приложение на Vue, TypeScript и Three.js. Деревянный ящик можно захватить и перенести вручную или нажать «Демонстрация», чтобы увидеть полный цикл.

## Запуск

Нужны Node.js 22 и браузер с WebGL 2. Если зависимости ещё не установлены, выполните `npm ci` из корня проекта. Перед повторной установкой остановите запущенный Vite клавишами `Ctrl+C`: Windows блокирует замену используемого файла `esbuild.exe`.

Для запуска выполните `npm run dev`. Откройте [http://localhost:5173](http://localhost:5173) или адрес, который напечатает Vite. Для просмотра собранной версии выполните `npm run build`, затем `npm run preview`.

## Проверки

- `npm run check` запускает проверку типов, модульные тесты и сборку.
- `npm run test:e2e` запускает браузерные проверки через установленный Chrome. Для установленного Edge задайте `PLAYWRIGHT_CHANNEL=msedge`.
- [Ручной маршрут с точными положениями ползунков](evidence/G3/README.md).
- [Проверка демонстрации, остановки и снимки G4](evidence/G4/README.md). Для повторной съёмки в PowerShell выполните `$env:CAPTURE_G4 = '1'; npm run test:e2e`.
