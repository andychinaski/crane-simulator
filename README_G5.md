# G5 — обновление Harness

Пакет подготовлен **для существующего** `andychinaski/crane-simulator`, ветка `master` в публичном GitHub на момент просмотра. Код приложения здесь не заменяется.

## Тебе нужно сделать ровно следующее

1. Распаковать **содержимое** ZIP прямо в корень существующего проекта (рядом с `AGENTS.md` и `package.json`). При распаковке должны появиться `docs/G5_ONBOARDING.md`, `.agent/G5_IMPLEMENTATION.md`, `tools/apply-g5.mjs`, `START_G5.txt`. Не создавать лишний уровень папок.
2. Отправить coding-агенту текст `START_G5.txt`. Остальное он сделает сам, включая регистрацию G5 в существующих MD.
3. При получении результата G5 принять его или перечислить замечания. До приёмки G6 не начинать.

## Какие существующие MD обновит скрипт

- `AGENTS.md`: обновит жесткое ограничение G1–G4, добавит контекст нового этапа.
- `docs/SPEC.md`: добавит G5 как расширение требований с точной ссылкой на спецификацию.
- `docs/ARCHITECTURE.md`: добавит правило отдельного UI overlay без пересоздания Three.js.
- `docs/QA.md`: добавит проверяемые R12–R17 и критерий приёмки G5.
- `.agent/TASKS.md`: добавит S05 и строку G5 в таблицу контрольных точек.
- `.agent/STATE.md`: добавит «G5 запланирован»; старую историю приёмок G1–G4 оставит.
- `.agent/DECISIONS.md`: добавит ADR-015 о UI-слое обучения и статусе выборов.

Скрипт специально не перезаписывает документы целиком, не трогает исходники и не удаляет старые решения. Повторный запуск не создаёт дубликаты G5. Если структура исходного Harness существенно отличается, скрипт сообщит об ошибке вместо молчаливой правки.
